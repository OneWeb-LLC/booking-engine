# Action: Work Pooled Calls

## Outcome

The next eligible pooled call is executed consistently and routed by its true outcome.

## Trigger and owner

Trigger: no appointment, Live Call, or due Assigned Task requires attention.  
Owner: the eligible pooled calling team; the accepting agent owns the active attempt.

## Rules

- Enter pooled work only after higher-priority work is clear.
- Accept the next eligible record; do not cherry-pick.
- Recheck current state before calling.
- Maintain one active outbound call objective.
- Let the definitive disposition determine the next workflow action.

## Completion and failure

Complete the attempt when the disposition, record state, and next action agree. If the objective is obsolete, resolve it without calling; if the queue is empty, escalate work supply to the Campaign Manager.
