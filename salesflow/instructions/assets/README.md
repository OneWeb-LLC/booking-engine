# Instruction Screenshot Assets

Store only approved, Salesflow-branded screenshots used by employee instructions.

## Folder convention

Create one client deployment folder and mirror the instruction path inside it. Example:

`[client]/appointments/book-appointment/step-01-open-calendars.png`

## Rules

- Use a non-production test contact whenever practical.
- Redact customer and sensitive information.
- Match screenshot numbers to the numbered walkthrough steps.
- Show only enough interface to orient the employee and identify the control.
- Replace obsolete screenshots instead of publishing multiple competing versions.
- Do not mark an instruction Client Verified until its screenshots, labels, permissions, and automation match the target account.
