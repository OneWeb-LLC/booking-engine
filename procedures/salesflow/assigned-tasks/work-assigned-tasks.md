# Procedure: Work Assigned Tasks

- **Roles:** All users
- **Work Priority:** Assigned Tasks
- **Last logic review:** 2026-08-23
- **UI verification:** Draft — client verification required

## Outcome

Due personal commitments are completed by the responsible person and converted into the correct next system state.

## Where to go

**Salesflow → Contacts → Tasks**

## Steps

1. Open **Contacts → Tasks**.
2. Filter to tasks assigned to you.
3. Sort or filter for overdue and due-now work according to client policy.
4. Open the highest eligible task.
5. Read the title, description, due time, related contact or opportunity, and recent context.
6. Perform the actual promised action.
7. Update the opportunity, appointment, or customer record when the state changes.
8. Add a meaningful note only when durable context was created.
9. Mark the task complete only after the action is performed.
10. If further work is required, create the correct new object rather than keeping the completed task artificially open.

## Create a task when necessary

1. Click **Add Task**.
2. Write an action-oriented title.
3. Add the information the owner needs in the description.
4. Assign the responsible user.
5. Set the real due date and time.
6. Associate the correct contact or opportunity.
7. Save and confirm the task appears for the owner.

## Do not use a task for

- an exact-time callback—create an appointment;
- pooled call work—use the Call Queue and Call Brief;
- historical context—use a note;
- a pipeline state—update the opportunity.

## Common mistakes

- Marking complete before doing the work.
- Leaving the assignee blank for personal responsibility.
- Writing vague titles such as “Follow up.”
- Creating a new task instead of updating the customer state.
