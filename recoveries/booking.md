# Booking Recovery

Use when contact or qualification occurred but no booking or live handoff was secured.

## Triggers

- booking page abandoned;
- conversation ended without a next step;
- decision-maker unavailable;
- information requested but no commitment made;
- live handoff failed;
- qualified contact did not select an appointment.

## Default owner

Booking Agent or configured pooled booking team.

## Success

Booking secured, live handoff completed, valid alternative next step created, or opportunity correctly closed.
