# Activation Recovery

Use when immediate new-lead contact fails.

## Triggers

- Zero Friction contact did not answer;
- no eligible agent accepted;
- call dropped;
- initial contact information was incomplete;
- the initial conversation did not start.

## Default execution

Send the configured acknowledgment, create a priority Call Queue entry with a concise Call Brief, and retry according to the client's speed-to-lead cadence.

Exit on meaningful contact, booking, invalid contact, DND, disqualification, or attempt exhaustion.
