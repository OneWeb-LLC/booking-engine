# Team Manager

## Mission

Maintain coverage, quality, accountability, and coaching across the Booking Engine.

## Daily operating cycle

1. Confirm appointment, inbound, and transfer coverage.
2. Review overdue Assigned Tasks and unaccepted handoffs.
3. Review queue depth and agent availability.
4. Review exceptions, complaints, and compliance risks.
5. Sample calls and documentation for quality.
6. Coach the system behavior causing the result, not merely the number.

## Accountability split

- Agents own availability, execution, dispositions, and documentation.
- Campaign Managers own qualified demand, workflow enrollment, cadence, and queue supply.
- Team Managers own staffing, coverage, coaching, quality, and accepted escalations.
- Salesflow Administrators own configuration and technical integrity.

## Coaching sequence

1. Identify the missed customer transition.
2. Confirm the correct path tier and Work Priority.
3. Inspect the call, record, disposition, and next system action.
4. Determine whether the failure belongs to skill, capacity, campaign, process, or system configuration.
5. assign the correction and verify it later.

## Scorecard

- service-level coverage;
- appointment punctuality;
- live-call acceptance;
- task aging;
- queue productivity;
- call quality;
- documentation compliance;
- handoff acceptance;
- conversion and Recovery performance by role.
