# Salesflow Instruction: Manage the Conversations Inbox

- **Roles:** Booking Agent, Sales Officer, Support Officer
- **Work Priority:** Live Calls or Assigned Tasks depending on the conversation
- **Last logic review:** 2026-08-23
- **Salesflow dependency:** Core capability
- **UI verification:** Draft — client verification required

## Outcome

New customer messages are read, correctly owned, answered, and converted into the appropriate next Salesflow action.

## Where to go

**Salesflow → Conversations**

## Click-by-click walkthrough

1. Open **Conversations**.
2. Use the approved filters for unread, assigned, unassigned, starred, or channel-specific conversations.
3. Open the conversation and verify the contact identity before replying.
4. Read the latest messages and meaningful record context.
5. Determine the customer's current Journey phase and requested outcome.
6. Reply using the approved script or a clear personalized response.
7. If the customer is available now, preserve live momentum through a call or appropriate handoff.
8. If an exact-time commitment is made, create an appointment.
9. If personal work remains, create or retain an Assigned Task.
10. Update the opportunity when the customer state changes.
11. Mark the conversation read only after the message has been handled or correctly owned.

## Completion standard

The customer received a response or the conversation has an accepted owner, due action, and accurate Journey state.

## Common mistakes

- Marking unread messages as read without handling them.
- Replying before checking appointment or conversion status.
- Creating a task when an exact-time appointment is required.
- Deleting conversations to clear the inbox.
