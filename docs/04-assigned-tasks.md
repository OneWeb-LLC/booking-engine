# Assigned Tasks

## Definition

Assigned Tasks are personal responsibilities with an owner and due time. They are not a substitute for pipeline stages, notes, appointments, or pooled call work.

## Use Assigned Tasks for

- promised deliverables;
- document review;
- issue resolution;
- approvals;
- personalized follow-up;
- escalation ownership;
- non-call administrative work.

## Do not use Assigned Tasks for

- every automated follow-up attempt;
- generic Call Queue records;
- exact-time callbacks;
- historical conversation summaries;
- workflow events that require no human action.

## Assigned versus unassigned

| Object | Meaning | Workspace |
|---|---|---|
| Assigned task | Personal responsibility | Assigned Tasks |
| Unassigned Zero Friction brief | Shared live opportunity | Live Calls |
| Unassigned Manual Action brief | Shared pooled call | Call Queue |
| Exact-time callback | Scheduled commitment | Appointments |

## Completion standard

Complete the task only after the promised action is performed. Add a note only when the outcome creates meaningful future context. If another commitment is required, create the correct next object instead of leaving the old task open.
