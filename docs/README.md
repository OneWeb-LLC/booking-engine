# Salesflow Booking Engine Documentation

Choose the shortest route to the information you need.

## I am working leads or customers

1. Open your [role playbook](../playbooks/README.md).
2. Follow the Four Work Priorities.
3. Open a [Salesflow procedure](../procedures/README.md) when you need exact clicks.
4. Use the relevant Recovery when progress breaks.

## I manage a team

1. Read the [Booking Engine framework](../framework/booking-engine.md).
2. Review [roles and ownership](../framework/roles-and-ownership.md).
3. Use the [Team Manager playbook](../playbooks/team-manager/README.md).
4. Monitor the [management system and KPIs](08-management-system.md).

## I configure Salesflow

1. Read the [Salesflow Administrator playbook](../playbooks/salesflow-administrator/README.md).
2. Use the [implementation guide](../implementation/salesflow/README.md).
3. Follow the [workflow specifications](../implementation/salesflow/workflow-specifications.md).
4. Start each client from the [client profile](../templates/client-profile.yaml).

## I maintain this repository

1. Follow the [AI maintenance rules](../governance/AI-MAINTENANCE.md).
2. Use the [procedure template](../templates/procedure-template.md).
3. Use the [role playbook template](../templates/role-playbook-template.md).
4. Re-verify click paths against the maintainer source ledger before publishing UI-dependent changes.
